# AiOrb Implementation Plan

> **For agentic workers:** Use executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Deliver a customizable, audio-reactive React orb without frame-driven React updates.

**Architecture:** A framework-independent Canvas renderer owns bounded drawing and reusable audio buffers. A React wrapper owns visibility, sizing, reduced motion, and resource cleanup. The docs playground owns microphone permissions and playback demonstrations.

**Tech Stack:** TypeScript, React, Canvas 2D, Web Audio, Vitest, existing Vite kit-docs.

## Task 1: Renderer and audio adapters

- [x] Create `common/aiOrb/model.ts` with state, preset, appearance, and quality contracts. Clamp finite numbers and validate hex colors.
- [x] Create `common/aiOrb/audio.ts`. Borrow analysers unchanged; create and close only stream-owned contexts. Return a synchronous disposal handle so unmount cannot race setup. Keep typed buffers between frames.
- [x] Create `common/aiOrb/renderer.ts`. Cache core/glow textures, seed effects once, blend states over 250 ms, and bound backing dimensions to 1024. Return `draw(time, delta, animated)` and `resize()` methods; the wrapper owns scheduling.
- [x] Add `react/src/components/AiOrb/model.test.ts` and `audio.test.ts` for invalid input, quality budgets, audio sampling, ownership, and failure cleanup.
- [x] Run `cd react && npx vitest run src/components/AiOrb/model.test.ts src/components/AiOrb/audio.test.ts`. Expect passing tests.

## Task 2: React lifecycle and exports

- [x] Create `react/src/components/AiOrb/AiOrb.tsx` and `index.ts`. Use effects and refs, never state for frame data. Observe resize, intersection, visibility, and reduced motion. Maintain one cancellable frame loop; stopped states render once.
- [x] Export from `react/src/components/index.ts`.
- [x] Add `AiOrb.test.tsx` covering Strict Mode, cleanup, pause/resume, source updates, static fallbacks, accessible naming, and no frame-driven React commits.
- [x] Run `cd react && npx vitest run src/components/AiOrb`. Expect passing tests.

## Task 3: Interactive documentation

- [x] Create `react/demo/src/kit-docs/components/ai-orb/AiOrbPage.tsx`. Provide all presets, states, colors, motion/glow, quality, pause, simulated audio, live microphone start/stop, errors, and an interactive sibling input.
- [x] Add analyser and stream examples, Key Accessibility, and every public prop in the API table.
- [x] Register lazy page `ai-orb` in `react/demo/src/kit-docs/registry.ts` under Feedback.

## Task 4: Verification

- [x] Run focused tests, `npm --prefix react run lint`, `npm run build:react`, and `npm --prefix react/demo run build`. Separate pre-existing failures from new failures.
- [x] Open the docs route. Inspect states, presets, small and large sizes, pause/resume, and reduced motion. Profile balanced rendering with a sibling input and record the browser/environment limitations.
- [x] Review changes for caller-owned resource cleanup, SSR safety, bounded work, and unrelated file preservation. Report completion and material limits.
